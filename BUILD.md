# YouTube Audio Ripper — Build & Installer Roadmap (All Phases)

This document covers producing distributable standalone executables and installers
for Windows, macOS, and Linux.

## Standalone Executable (PyInstaller)

The repo includes a PyInstaller spec at `build/youtube_ripper.spec`.

### Prerequisites

```bash
pip install pyinstaller customtkinter yt-dlp ffmpeg-python
```

> Note: `ffmpeg-python` is a Python wrapper. The `ffmpeg` binary itself must be
> installed on the build machine and bundled separately (see below).

### Build Windows EXE

From the repo root on Windows:

```bash
build\build_windows.bat
```

Output: `dist/YouTube Audio Ripper.exe`

### Bundle FFmpeg with the executable

PyInstaller does not bundle system FFmpeg automatically. Options:

1. **Bundle `ffmpeg.exe` as a data file** — add to `datas` in the spec:
   ```python
   ("path/to/ffmpeg.exe", "."),
   ```
   Then resolve it at runtime with `sys._MEIPASS` when frozen.

2. **Ship FFmpeg alongside the EXE** in an installer (recommended for MSI).

3. **Require user to install FFmpeg** — the app's pre-flight check shows a clear
   error message and disables the Start button.

## Installers

Platform-specific installers are not generated by this repo directly. The
recommended approach per platform:

### Windows — MSI

Use [Inno Setup](https://jrsoftware.org/isinfo.php) (free, scriptable) or the
WiX Toolset to build an MSI that:

* Installs `YouTube Audio Ripper.exe`
* Bundles `ffmpeg.exe` in the same install directory
* Creates a Start Menu shortcut and desktop shortcut
* Adds an uninstaller

Example Inno Setup script snippet:

```iss
[Setup]
AppName=YouTube Audio Ripper
AppVersion=2.0.0
DefaultDirName={pf}\YouTube Audio Ripper

[Files]
Source: "dist\YouTube Audio Ripper.exe"; DestDir: "{app}"
Source: "ffmpeg.exe"; DestDir: "{app}"

[Icons]
Name: "{group}\YouTube Audio Ripper"; Filename: "{app}\YouTube Audio Ripper.exe"
Name: "{commondesktop}\YouTube Audio Ripper"; Filename: "{app}\YouTube Audio Ripper.exe"
```

### macOS — DMG

Build the `.app` bundle with PyInstaller (spec includes `BUNDLE` entry), then:

```bash
hdiutil create -volname "YouTube Audio Ripper" -srcfolder "dist/YouTube Audio Ripper.app" -ov -format UDZO "YouTube Audio Ripper-2.0.0.dmg"
```

Code-sign with an Apple Developer ID for Gatekeeper compatibility.

### Linux — deb / rpm

Use [fpm](https://github.com/jordansissel/fpm) to build packages from the
PyInstaller `--onefile` output or from a directory layout:

```bash
fpm -s dir -t deb -n youtube-audio-ripper -v 2.0.0 \
    dist/YouTube\ Audio\ Ripper=/usr/bin/ \
    assets/icon.png=/usr/share/icons/hicolor/256x256/apps/
```

RPM equivalent with `-t rpm`.

## Auto-Updater

The app checks GitHub releases on startup (`check_for_updates()` in `rip_gui.py`):

* Hits `https://api.github.com/repos/cjps4linux-creator/youtube-audio-ripper/releases/latest`
* Compares the tag semver against `CURRENT_VERSION`
* Logs a message if a newer version is available

To ship updates:

1. Tag a release on GitHub (e.g. `v2.0.1`)
2. Attach the platform installer/EXE as a release asset
3. Bump `CURRENT_VERSION` in `rip_gui.py` for the next release

## Code Signing — Skipped

This project does **not** purchase a code signing certificate. Distributable
artifacts (EXE, ZIP, installer) are unsigned. Windows users will see an
"Unknown publisher" SmartScreen warning on first run — click **More info →
Run anyway**.

If you ever want to sign artifacts, add a `signtool.exe` step to
`.github/workflows/release.yml` and purchase a certificate from DigiCert,
Sectigo, or GlobalSign (~$250–$500/year). See `CODESIGNING.md`.
